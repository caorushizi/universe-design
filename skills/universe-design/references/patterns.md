# 页面与业务组合模式

这些是组合建议；只实现用户需要的流程，不强制每页都采用统一外壳。

## 列表与批量操作

导航 → 标题和主动作 → 筛选 → 表格/列表 → 分页。字段选择基于实际业务比较需求。默认常用列可见，次要动作收更多；金额右对齐。选中行显示批量操作栏，跨页选择按稳定 ID 保存，并写清是选当前页还是全部结果。筛选改变时保留还是清空选择由业务决定并明确提示。

首次载入可骨架，刷新保留旧数据加 busy，零结果提供清筛选，失败提供重试。批量部分失败逐项返回，不给全成功反馈。相关规范：table、pagination、checkbox、dropdown、empty、loading、toast。

## 设置与表单

按用户理解分组，默认顶置标签。字段顺序跟随任务；必填和可选表达统一。依赖字段显示/禁用由开关即时响应，但页面级保存仍保留草稿。保存区域有单一主动作；错误紧邻字段，跨字段错误放组内。离开未保存页面保留恢复路径，避免多层确认弹窗。

可用整个页面、Dialog 或右侧 Sheet：短确认用 Dialog，保留列表上下文的编辑用 Sheet，大量内容和可分享地址的任务用详情页。相关规范：form、input、select、switch、dialog、drawer、notice。

## 多步流程

3–7 个清晰步骤，每一步有任务结果。前进先验证本步，后退保留输入；完成记录跟随真实业务成功。可跳转的步骤用按钮/链接，未开放步骤说明原因。处理中提供可恢复进度，终局显示下一步行动。相关规范：steps、form、progress、timeline。

## 数据分析

先明确比较/趋势/分布/占比问题，再选图。类别标签过长选条形，多个时间序列用折线；不要把平滑插值称为观测。顺序色必须跟随数值顺序；功能色的含义在图例中说明。窄屏减少网格和刻度密度，保留数据、图例和单位，提供可访问表格。相关规范：data-visualization-design-guide、table、responsive-design-guidelines。

## 多语言与内容

采用消息 ID 与整句翻译，避免多个片段拼句。数字/时间按 locale，跨时区任务显示时区，值存储与显示格式分离。优先自然增长；操作组可折行、表单可单列，重要按钮不省略。RTL 使用 padding-inline、margin-inline 与 start/end；仅方向性图标镜像，媒体/品牌图标保留。

## 添加新组件

记录：适用问题、何时不用、结构、variant/size、受控值、状态、键盘、提交/取消、响应式、内容规则、源页与工程差异。CVA 管外观枚举，语义 token 管主题，业务 hooks 管请求。先复用现有 primitive；确实缺少时组合并验证，不通过动态 className 绕过 lint。
