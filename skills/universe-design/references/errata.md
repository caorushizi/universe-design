## 补充而非官方参数

- 深色主题、focus ring、hover/pressed 色阶、150/200/250ms 时长、系统字体栈、z-index，以及 React API 均为工程补充。
- Switch 示例尺寸40×22是工程选择；图像没有标尺寸，不能靠缩放截图推导为官方值。
- 成功/警告/错误原色与语义文本/按钮色分开，后者因对比度调整。
- Tailwind、shadcn 版本可能变化。示例锁文件与已验证版本为依据，升级后重新验证，不把 `latest` 当固定版本。
- 61 页正文已整理；仅11张关键图核对，其余视觉细节需按任务查原图。`figures.json` 保留全部图片引用，未把外部图片复制进分发包。
