# 基础与 Token

## 层次与责任

基础值（颜色、间距、尺寸）→ 语义（surface、text、action、feedback）→ 组件（Button variant/size）→ 页面组合。组件的主题、状态和密度在组件内维护；页面不用散落 HEX 和任意像素改样式。样例的 `theme.css` 是可运行入口，以下数值标记决定是否可称为官方来源。

[样式页](pages/style.md) PC 向下阴影，每组是三层 x/y/blur/spread/alpha，颜色 #1F2327：

| token | 三层值 |

| S1 | 0/1/2/-2/.02；0/2/4/0/.02；0/2/8/2/.02 |
| S2 | 0/2/4/-4/.02；0/4/8/0/.02；0/4/16/4/.02 |
| S3 | 0/3/6/-6/.05；0/4/8/0/.03；0/6/18/6/.03 |
| S4 | 0/4/8/-8/.06；0/6/12/0/.04；0/8/24/8/.04 |
| S5 | 0/6/12/-10/.06；0/8/24/0/.04；0/10/36/10/.04 |

CSS 中保留这些值。暗色阴影加深为工程适配。z-index 的 sticky10、浮层40、modal50、tooltip60、toast70 为本地约定；嵌套浮层在所属模态层内管理，不能仅靠无限增大数字。

## 响应式

[原文](pages/responsive-design-guidelines.md) 的五档：<600 / 600–1023 / 1024–1439 / 1440–1919 / ≥1920。
使用 `ud-sm`/`ud-md`/`ud-lg`/`ud-xl`，全部以 rem 定义：37.5/64/90/120（按默认 16px）。保留 Tailwind 原有断点以兼容外部代码，但 UD 组件不用它们冒充官方档位。

- 桌面内容网格 12 列，沟槽16、边距24；平板8列，沟槽8、边距16；手机4列，沟槽8、边距16。
- 栅格范围扣除固定侧栏；固定内容宽参考1136。窄屏 min-width:0，重要操作可另起一行。
- 模态参考宽420/600/840/1080，必须受 viewport 安全区限制。小屏可全屏；复杂数据表允许横向滚动或提供摘要视图。
- 测 375/600/1024/1440/1920 和断点相邻宽度，200% 缩放、长译文、空与大数据。

## 动效与主题补充

150ms 快速状态，200ms 常规，250ms 进入；退出可短50ms。示例曲线与时长是工程设定，不声称源文精确值。只过渡必要属性，减少动画时关闭非必要移动和循环。

`.dark` 切换语义变量；SSR 应在首次渲染前按项目机制确定主题以避免闪烁。支持系统偏好/用户覆盖时要明确优先级。深色模式需复核图表、遮罩、浮层、所有状态，不能只反转颜色。

实现参考：[shadcn theming](https://ui.shadcn.com/docs/theming)、[Tailwind theme](https://tailwindcss.com/docs/theme)。
